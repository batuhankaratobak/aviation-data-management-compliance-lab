# Evidence Directory

Bu klasör gerçek denetim kanıtı içermez. Yalnızca eğitim amacıyla hangi tür kanıtların beklenebileceğini açıklamak için kullanılabilir. Gerçek müşteri verisi, şifre, API key, kişisel veri veya gizli bilgi eklemeyin.

Örnek kanıt türleri: erişim gözden geçirme tutanağı, yedekleme iş özeti, geri dönüş testi planı, farkındalık katılım kaydı ve olay tatbikat notu. Bunlar oluşturulmuş gerçek kanıtlar değildir.

# CISO Assistant Local Setup

Bu belge, eğitim amaçlı yerel çalışma düzenini açıklar. Proje klasörü dışında veri kaynağı, gerçek müşteri verisi, şifre veya API key kullanılmaz. Yerel kullanımda yalnızca örnek kayıtlar ve kurgusal şirket bilgileri işlenir.

Kurulum sonrası `python scripts/validate_project.py` çalıştırılır. CISO Assistant zorunlu değildir; istenirse yalnızca opsiyonel bir eğitim aracı olarak değerlendirilebilir. Herhangi bir entegrasyon eklenirse gizli değerler dosyaya yazılmaz; `.env` dosyaları commit edilmez. Bu çalışma gerçek ISO sertifikası veya resmi denetim değildir.

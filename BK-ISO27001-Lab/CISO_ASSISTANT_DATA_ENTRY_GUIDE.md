# CISO Assistant Data Entry Guide

1. Önce varlıkları `Asset Inventory` sayfasına girin.
2. Riskleri varlık ID’leriyle ilişkilendirin; skor formülünü değiştirmeyin.
3. Treatment kayıtlarında hedef tarih, sorumlu ve residual risk alanlarını güncelleyin.
4. SoA durumunu gerçek uygulanmış gibi göstermeyin; yalnızca Planned, Documentation Only, Partially Implemented veya Evidence Pending kullanın.
5. CAPA kapanışına yalnızca gerçek eğitim çalışmasının sonucu olan örnek açıklamalar yazın.

Gerçek müşteri verisi, şifre, API key veya gizli bilgi girmeyin. Kanıt alanları örnektir. Bu belge eğitim amaçlıdır; gerçek ISO sertifikası ve gerçek denetim değildir.
